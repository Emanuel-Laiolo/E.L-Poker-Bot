## Description
A Python-based poker bot designed to play No-Limit Texas Hold'em autonomously, 
from preflop to the end of each hand, in an authorized environment.

## Objetive
The objective is to build a bot that uses precomputed preflop strategies and GTO-based postflop decisions.

The initial focus will be on implementing a reliable strategy engine. Exploitative strategies may be incorporated in later versions.

## Features
-Precomputed preflop ranges.
-Computer vision and OCR to recognize cards, player positions, stacks, pot sizes, and betting actions.
-GTO-based postflop strategy.
-Opponent history tracking.
-Automated execution of poker actions.
